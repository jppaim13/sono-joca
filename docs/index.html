Instale o app primeiro

No iPhone, este app só funciona instalado na Tela de Início — o login e os dados salvos dependem disso.

  1. Abra este link no Safari (se ainda não estiver).
  2. Toque no ícone de Compartilhar, na barra do navegador.
  3. Escolha "Adicionar à Tela de Início".
  4. Abra o app pelo ícone criado, não mais pelo Safari.

Como montar o atalho

No app Atalhos: novo atalho → ação "Obter conteúdo de URL" → método POST → corpo JSON com token e command. URL:

Comandos: sleep_start, sleep_stop, feed_start (com side: peito-e/peito-d), feed_stop, diaper (com kind), bottle (com ml), status (pergunta tipo "há quanto tempo está acordado?" — a resposta vem em text, dá pra usar com "Repetir texto" pra Siri falar).

Depois é só adicionar o atalho pronto ao widget da Tela de Início, ao Apple Watch, dizer o nome dele pra Siri, ou associar ao Toque nas Costas / botão de Ação / Central de Controle (iOS 18) nos Ajustes do iPhone.
